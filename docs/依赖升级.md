Cronet 和官方面板未提供可直接采用的语义化稳定发布号，因此分别固定官方内核要求的模块提交、官方已部署面板提交。内核、Cronet 和面板归档固定 SHA-256；不能随意将 Cronet 替换为独立最新主干，否则可能破坏内核动态库兼容。Jest 的 Babel 兼容分支使用最新 7.29.7，与 ESLint 的 Babel 8 分开解析；未用 legacy-peer-deps 或 force 忽略冲突。npm 间接依赖按上游兼容范围解析，必要的安全覆盖记录在 package.json，不能将每一层依赖强行换成不兼容的大版本。上游稳定组件仍锁定了 gen-mapping 0.4.0-beta.0、gensync 1.0.0-beta.2、postject 1.0.0-alpha.6 三个子依赖；它们不是本项目主动选用的预发布主组件，不宣称整个依赖树都具有稳定版标签。Go 模块图中上游测试/分析工具的版本也不等同于实际 vendored 运行库。

## 升级兼容修复

- TypeScript 7 使用 Node16/bundler 模块解析，移除已失效的 baseUrl/node10 配置；保留 strict、unused、return 等检查。
- 测试由 SWC 编译，独立 `test:types` 仍先于默认测试运行；未使用只转译来替代类型检查。
- Tailwind 4 改用官方 Vite 集成，迁移类名、CSS 变量语法，保留原主题和容器尺寸；实际 Electron 页面与节点协议表单已检查。
- js-yaml 5 显式启用标准 YAML merge tag，保留 Clash 常用 `<<` 字段继承；补充继承协议、服务器、认证、TLS、WebSocket 字段及覆盖端口测试。
- Zustand 5 将空数组回退移出 selector，避免空配置时返回不稳定快照而持续渲染。
- plist 5 按官方 ESM API 动态加载；Electron 44 移除的登录项字段不再调用，开发模式不注册系统登录项。
- 内核管理 API 使用 v1.14.2 完整官方 StartedService proto，删除手选的旧 alpha 字段子集。独立 wire 夹具验证 Tailscale 字段号，真实内核验证 Status、选节点和关闭连接。
- 本地开发版不自动检查发行包更新；安装包仅手动触发，推送代码只运行验证。

## 助手协议和生命周期

助手跨进程通信改为标准 HTTP JSON-RPC 2.0，由维护中的库处理请求、通知、批处理和错误；原来的按行拼接、自有协议数字协商不再作为线上协议。业务方法和能力列表仍是应用接口，不是新增代理协议。仅监听本地 Unix socket / Windows named pipe；macOS/Windows 使用 Bearer 认证，Linux 使用 SO_PEERCRED 校验调用者。

助手版本 `0.1.0` 是应用实现版本，JSON-RPC 协议版本固定为标准 `2.0`。更新能力按 `capabilities` 判断，不要求所有操作跟随自有协议数字升级。

stop、cleanup、freeport、服务退出只处理助手当前托管的进程，删除按名字、映像路径扫杀及旧 Clash API 端口清理。助手在进程 Wait 和转发恢复完成前保持 stopping，客户端轮询最终 stopped，期间拒绝新 start。外部监听进程报告 foreign，不强杀。

macOS/Linux 仅在需要时修改转发 0→1，记录原状态，失败或退出恢复本次修改；Windows 使用 [Microsoft Set-NetIPInterface](https://learn.microsoft.com/en-us/powershell/module/nettcpip/set-netipinterface) 的 ActiveStore，删除持久注册表写入。不开转发时不修改转发状态。

日志与配置边界增加普通文件、软链接/FIFO/硬链接检查；Linux 使用目录 fd 与属主检查，Windows 使用真实文件句柄路径与 reparse 校验。Windows 配置句柄保留到进程退出，防止运行中被替换为其他路径。

## 本地验证与范围

在 macOS ARM64 执行默认测试、类型检查、lint、构建、官方内核配置检查，结果见验证报告。共享 RPC 边界测试和 macOS 助手 `go test -race` 通过，Linux/Windows 转发纯逻辑测试通过；Windows 实际命令/生命周期代码在 Unix 隔离 harness 中的竞态测试通过。macOS ARM64/x64、Windows AMD64、Linux AMD64 助手交叉构建通过，Linux/Windows 专属测试二进制也能交叉编译。

新助手与官方 1.14.2 内核实际联调：认证错误返回 401；启动后经代理 HTTPS 返回 204；gRPC 状态字段、选节点、关闭连接成功；清理后助手报告 stopped，外部测试进程仍存活；目录外日志被拒绝。本次联调为普通用户独立进程，不安装 root 服务，不接管系统网络。

RPC 边界覆盖通知无响应、混合批处理、空批、非法 JSON、null、非法 ID、分块 HTTP、请求大小和调用者 context 传递。不是仅检查 JSON 可以序列化。

未完成新助手 root 安装和 TUN/真实系统转发验收，也未执行 Windows API/SCM/PowerShell 和 Linux ambient capability 真机测试；这些限制不被交叉编译或隔离 harness 替代。协议兼容仍以官方内核支持范围为准，供应商不可达节点不会因为依赖升级自动恢复。
