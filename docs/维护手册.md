# 暗影VPN 维护入口

前端唯一入口为 `web/`，规范见 [前端规范](规范/前端.md)，来源及桌面差异见 [前端改造](前端改造.md)。`src/renderer-domain/` 仅保留原有纯函数与回归测试，不作为第二套界面。后端保留 `src/main/`、`src/shared/` 和各平台 helper。

根目录执行 `npm ci`，再执行 `pnpm --dir web install --frozen-lockfile`；`npm run dev` 同时启动 Vite 和真实 Electron。修改主进程后需重新启动开发进程，不能把前端热更新当成主进程已更新。

查看和调整界面直接使用 `npm run dev` 打开的真实 Electron 客户端。`web/src/` 的页面、样式和交互通过 Vite / React Fast Refresh 自动更新，通常不需要关闭客户端、重新编译整个项目或打包安装包；边界变化可能触发页面刷新。主进程或 preload 改动需重新执行 `npm run dev` 编译并重启客户端；原生 helper 改动需单独构建和验证。5172 网页演示预览入口已移除，避免模拟数据与真实运行状态混淆。开发服务器仅用于客户端资源与热更新，不是独立网页版产品。

交付执行 `npm test`、`npm run test:core-gate`、`npm run lint`、`npm run typecheck:renderer`、`npm run build` 以及 `pnpm --dir web check`。前端完整检查覆盖静态设计、单元测试、类型、ESLint、双语词典、依赖补丁、构建与真实浏览器。涉及共享交互时可补充 `pnpm --dir web test:ui:full`。界面变更另在真实 Electron 中验证，浏览器模拟 IPC 不替代系统服务与真实网络验收。

真实配置保留在应用独立用户目录，订阅 URL 与凭据不得放入 Git、测试夹具或示例日志；报告仅记录聚合结果。浏览器检查输出在 `web/.playwright/`，不提交。当前不推进安装包，除非用户另行要求。

测速并发上限由 `src/shared/speed-test.ts` 的 `SPEED_TEST_CONCURRENCY` 统一定义，当前为 16，主核探测池大小与其一致；代理与入口检测各自最多 16 并发。主核每个 worker 固定绑定一个探测槽，选择、代理请求和端点诊断完成后领取下一个节点；不等待整个批次。临时核和直连入口检测也使用完成即补位的并发队列。节点代理测量（默认与备用目标合计）保留 8 秒预算，入口 TCP 检测保留 4 秒预算；TCP 成功不代表代理可用。不同测速请求仍由既有会话编排合并或排队，避免并发创建多个临时核；同一轮节点检测是并行的。

## 日志问题排查

日志页面为专用连续查看器，搜索可匹配本地化文案、原始内容、来源及完整堆栈。INFO 为信息，不代表所有后台操作成功；WARN 为警告，ERROR/FATAL 为错误。暂停仅停止画面跟随，日志仍采集；恢复补回缓冲。内存/画面和导出是有限近期记录，早期事件应查轮转文件，不能将看不到当成未发生。

排障优先附“导出诊断报告”的本地 Markdown。按 `sessionId`/`sequence` 对齐事件，查看 `writeErrors`、`droppedWrites`、`criticalDropped`、`uiDropped`、`memoryEvicted`、`pendingWrites`、`flushComplete`，先确认日志是否完整，再对比应用事件、内核配置、singbox.log 和启动 stderr。日志文件为一行一个 JSON；原始应用文本与 eventId/eventArgs 一并保留，用于跨语言还原。

React LogViewer 6.6.0 的 ES/CJS 测量回调补丁由 pnpm-workspace.yaml 和锁文件持有，补丁源码在 web/patches。测量延迟到动画帧，合并同元素通知并在销毁时取消，避免 Chromium/Electron 的 ResizeObserver 循环。升级后必须检查真实入口哈希、测量专项及 Electron 原生界面，不能只删除补丁或过滤告警来让检查通过。

## 兼容内核

版本与 SHA-256 统一维护 src/shared/compatibility-core-manifest.json；升级先核验官方稳定发行资产，再补齐四平台归档与二进制摘要。运行 npm run fetch:compat-cores 获取内核；npm run test:core-gate 必须成功。Xray / mihomo 以独立子进程运行，临时配置位于仓库外并限制为 0600。程序停止时同步请求退出，最长 2 秒后终止残留进程；只清理本实例创建的临时目录与进程。

新增 native 协议须逐项验证导入、原生字段保留、内核配置检查、完整代理请求、TLS 校验和停止清理；不能把 TCP 监听就绪当作节点可用。覆盖范围见多内核兼容.md。兼容内核不使用 sing-box 的更新渠道：版本由 manifest 固定，更新辅助内核不得覆盖 FlowZ、FlClash 或其他后台服务。
