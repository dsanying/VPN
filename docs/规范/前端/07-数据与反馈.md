# 数据与反馈

配置、检测结果与数据库由业务层统一管理，界面读取快照并订阅变更。新配置或相关配置变更触发对应范围初始化；页面访问不触发检查或确认轮询。六小时后台策略属于本产品，不是通用客户端的固定要求。

测速必须经代理进行真实 TLS 请求；TCP 端口成功不能表示代理可用。检测记录保存到数据库并与对象、配置版本关联，删除对象时清理关联记录，失败更新保留原节点和用户输入。

操作结果统一通过 utils/feedback.ts 的右上角通知，按结果内容去重；失败保留编辑输入。读取失败就地提供重试，表单校验用字段提示，进度与持续权限条件直接展示。未知进程或能力明确表示未知，不伪造名称、图标或成功。
