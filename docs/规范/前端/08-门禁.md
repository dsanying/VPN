# 客户端门禁

本项目使用 React + Ant Design 公开 API 与独立客户端共享层；客户端体验以 [客户端规范](../客户端.md) 为准。历史账户后台、财务组件、Cron 编辑器和 Tabs 演示不属于当前客户端，原检查器已经退役，适用要求由当前组件和实际业务页面验证。

统一入口为 `pnpm --dir web check`，执行源码结构、主题输出、双语文案、单元回归、时间、真实依赖补丁、类型、零警告 ESLint、生产构建和浏览器测试。`docs/规范/manifest.json` 登记阶段和实际命令，执行来源为 `web/scripts/client-checks.mjs`；任一失败立即停止，空检查和缺失退出状态不能算成功。`--phase static/build/ui` 仅供明确专项验证；affected/staged 保守执行全部静态检查，不因未登记改动跳过验证。

静态 AST 门禁扫描全部客户端 UI，拒绝内容折叠、解释性 placeholder 和常驻字段说明，配套正反夹具拒绝别名、命名空间、createElement、spread 及越界路径。时间门禁扫描页面、业务组件与共享时间工具。字典检查验证双语键、参数及嵌套循环；字典清理只在显式 prune 时写入，先解析完整依赖，再删除未引用内容。主题 CSS 与角色生成源必须一致。

单元测试保留请求生命周期与 StrictMode 过期结果、取消和卸载边界，JSON 校验、路由匹配、数字显示、时区及夏令时、颜色转换、依赖构建审计和真实运行时补丁。Drawer、Picker、util 与日志查看器沿实际安装入口核对版本和 ES/CJS 内容，不凭 package.json 声称修复已命中。

浏览器覆盖 320/768/1440 宽度、亮暗主题、中英文的实际页面，检查可读性、完整内容、对齐、操作图标、可访问动作名称、弹层边界及窗口内滚动。空间不足时允许操作组换行并保留文字，不能强制所有按钮变成难辨认的图标。节点是完整可滚动列表，分页表格默认十条，20/50/100 候选；第二页重排不改第一页。保存失败保留输入、取消还原、成功关闭。Tooltip 只在窗口不足时折行，动画结束后核对真实文字几何。

业务回归同时验证图标、出口图真实完整数据与筛选交集、测速结果记忆、节点组操作、无手动自动识别选项、字段问号、规则顺序与说明、设置必要项、日志多选和虚拟滚动、更新动作范围。禁止为了通过门禁删掉实际业务断言或隐去错误。

浏览器 mock 只证明渲染及 IPC 契约。原生服务、VPN 授权、TUN、自动启动、持久化、安装升级和软件/内核更新另行在目标宿主验证。发行入口使用 `scripts/check-client-platforms.mjs --release` 检查同一版本、提交和实际平台证据；未测平台不能复用别的平台报告，源码许可未解决不能公开分发。
