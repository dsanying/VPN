# 暗影VPN 客户端规范

当前选型与验收范围见 [平台与发布](平台与发布.md)。桌面采用 Electron，共享 React + Ant Design；Android 按需使用 Capacitor，不能把宿主打包完成当作 VPN 功能完成。

本文件是本项目客户端的唯一规范来源，独立维护；运行、测试和门禁不引用任何仓库外路径。

共享前端使用 Ant Design 公开组件、项目主题和独立客户端门禁；业务契约以本文件为准。内容分区始终显示，禁止 Collapse、SecondarySection、details 等。网站连通性、节点配置和规则组合条件直接展示，由 DesktopSection 统一组织标题与内容。历史网页实现登记仅用于来源审计，不作为当前组件或门禁依赖。

标题栏、导航和状态栏固定在窗口内，主内容有纵向滚动与可见滚动条，键盘可聚焦 main，路由切换回顶。节点页按用户要求使用共享 AppPage 的 contained 模式：来源与分流同行，控件固定在列表上方，节点列表独立滚动；筛选条件按容器宽度整项换行，窄窗口控件满宽，订阅管理在独立节点组表格展示，保留完整内容和列表高度。菜单、选择器和窄窗口导航抽屉仍属于操作入口，不是内容折叠；不新建用于隐藏设置的手风琴或多层详情页。

连接页是只读实时看板，可见时持续接收连接更新，不提供暂停、关闭单条/全部连接或操作列。

全局状态栏统一显示连接状态、当前节点与出口，节点和连接页不重复状态横条。就地编辑，合并添加入口；实时曲线、连接拓扑显示真实采集值与完整集合，不伪造不可观测的应用。

用户动作由真实宿主结果触发右上角通知，只经共享 feedback 入口；同一操作结果不在页面、表格或抽屉重复插入 Alert / QueryErrorAlert。失败保留输入与原配置，后台轮询不刷屏；字段校验、读取失败、实际进度与持续前置条件按用途就地展示。操作验收使用 web/tests/ui/operation-notification.ts，覆盖位置、唯一性、失败保留输入、跨页结束及关闭后无残留。中文与英文保持同源，打开链接与危险动作采用语义样式。原生权限、文件、剪贴板、链接及网络不以浏览器模拟冒充验证。

常显门禁：pnpm --dir web check:client；expanded 与 time 检查已纳入完整 check 的 static 阶段，覆盖 web/src 与 update-popup 全部 UI 源码，共享层 src/components/client 与通用组件目录照常受检。表格与查询清单登记 src/pages、src/components/vpn、src/layouts、update-popup，新增业务目录必须同步 manifest 与 design-system.project.json。静态门禁覆盖显式折叠组件与别名，无法证明自制隐藏逻辑不存在，必须补真实客户端验收。

时间使用 utils/dateTime 唯一入口：getDeviceTimeZone 动态识别设备 IANA 时区；now 获取当前时刻，parseServerTime 保留接口偏移并按设备换算，无偏移默认本地、有明确来源时区则显式传参。统一 formatDateTime/formatDate/formatClockTime 等展示，不原样显示 ISO 的 T/Z，不固定上海；存储和协议仍保留实际时刻及原序列化契约。无效值显示空态，纯日期按日历值处理，DST 日界按当地偏移计算。门禁 check:client:time 已加入 check:client 与完整 check 的 static 阶段；跨时区单测覆盖五个时区与夏令时、存储往返、无效输入。


## 仅 TUN 接管

连接只使用 TUN，节点页和托盘不提供接管方式选择或强制 TUN 开关。共享 `prepareAutomaticTakeover` 在配置读写、节点页、托盘、开机连接和后端启动/重启统一规范为 TUN + autoRoute；智能分流、全部代理和直连仅决定出口，不改变接管方式。TUN 失败如实报错，不降级系统代理。

连接不写系统 HTTP/HTTPS/SOCKS 代理或代理忽略清单，不注入 8.8.8.8；内部 DNS 解析器仍可配置。TUN 连接自动接管系统 DNS（指向隧道内地址）：macOS scoped resolver 绑定物理接口、绕开路由劫持，不接管则本机应用拿真实 IP、FakeIP 对本机应用不生效。接管由 SystemDnsManager 托管（marker + 停止/退出/崩溃恢复 + 启动 reconcile），内网/captive 域名经原 LAN 解析器解析；旧 DNS 接管开关已移除入口，接管恒开。只恢复由本应用旧会话留下且仍可确认归属的接管，保留其他软件和用户的设置。无法确认原值的历史代理忽略清单不能直接清空。

助手常驻，连接时启动 TUN，断开撤销本应用临时接口和路由；断开不维持隧道。TUN 仍会临时改变路由和系统 DNS（接管由 SystemDnsManager 托管并在停止/退出/崩溃时还原），不能声称对网络毫无影响。内网、captive 域名经原 LAN 解析器解析；企业 VPN 和其他隧道的实际兼容性须按平台验证，不能承诺所有网络都正常。

## 自动智能分流

规则页只展示当前网络地区与实际准备状态，不提供手动地区、反向分流或本地分流总开关。地区来自直连网络出口：内核运行时经过固定直连探针入口，停核时使用不采用系统代理的 Node HTTPS；代理节点的出口不得作为本地地区。网络接口地址变化与唤醒触发重识别，地址不变时十分钟刷新，失败一分钟重试。获取、规则下载与旧请求完成均有代号隔离，旧网络结果不能覆盖新网络。

自动策略仅在现行 ISO 地区码与国家 IP 规则均就绪时开启。同国家/地区的目标 IP 直连，其余代理；域名通过实际解析及 DNS 响应 IP 匹配判定，FakeIP 不参与地理判定。显式应用与自定义规则、局域网和内核基础流量规则优先。未知地区或规则不可用保留真实状态，暂走代理，不默认中国，不用域名品牌或顶级域猜测国家。旧地区配置仅用于备份及独立生成器兼容，应用运行时以自动策略覆盖，不改写用户备份。

国家/地区是公网出口与 IP 数据库归属，不是 GPS 物理定位，也不是网站运营主体或账户地区。上游路由器/其他 VPN 已改变全网出口时，客户端无法保证恢复原本物理位置；CDN、Anycast 与数据库更新也会影响目的 IP 归属。界面保持简短，能力边界记录在本规范与兼容性说明。

## 空间利用与验收

全页检查节点、连接、规则、应用分流、日志、设置及其编辑表单。内容始终展开，不能用折叠、省略真实条目或减小字体和点击目标来减少高度。操作按钮放在所属区块标题旁；同组短字段并排，长文本编辑单独占行。设置页只保留局域网绕过开关，普通网站直连由规则页统一管理，不再重复提供直连地址清单。密码锁和整份配置编辑器不属于客户端必要功能，移除其入口和自动触发；维护低频操作集中在所属区块的“更多”菜单。

少量同质指标使用 SummaryStrip 按内容并排。InformationFieldGrid 用于异构只读字段：240px 单格预算、最多四列，按容器宽度逐级降列；标签在上、值在下，连续排布，长值完整自然折行。网站名称、状态与 HTTP 结果保留全部真实记录，不以表格或内容折叠隐藏未测项；中英文与缩窗均验证内容可达。

客户端主题中表格单元内边距为纵向 8px、横向 12px，卡片标题高度为 40px；控件、字号仍沿用公共 token。共享 Table 对含提示图标的 React 表头测量完整固有宽度，不能只按单元值把标题挤到相邻列。出口和已有链路同行显示，不重复一遍出口名；出口图仅展示可确认的用户应用连接，连接页保留完整快照及分页、滚动访问。

连接图使用共享高度档，分析图基础 CHART_HEIGHT=336px 保留。连接出口图采用本机 → 域名/应用 → 出口的三层桑基图，共用出口合并，不按每个分组重复出口。带宽按真实连接数计算并守恒，不能冒充逐连接流量；直连绿色、代理蓝色、阻断红色、未知使用次要色。应用采用图标与名称，标签间距保证最小分支可读。完整 SVG 按实际分组数定高，窗口内视区最多 CHART_HEIGHT=336px，完整集合通过局部滚动访问，不做 TopN/其他合并。出口图先筛选应用范围，再在聚合前搜索范围内的全部连接，匹配应用、域名/IP、进程路径、协议、端口、出口与规则；图与统计同步筛选，完整连接明细独立保留全部记录。图形稀疏不等于浪费空间，验收依据可读行高、角色高度、布局几何和完整集合，不能以非透明像素比例迫使图形拉满。

专项 web/tests/ui/desktop-density.spec.ts 检查网站全集、结果同行、标题与刷新同排、指标列数、字号/单元溢出与图表高度；全页面 real-pages.spec.ts 覆盖六个页面、320/768/1440px、中英与亮暗主题；connections-live-traffic.spec.ts 保留完整连接的完整集合验收。最后须实际查看 Electron 热更新结果。

表格分页统一默认每页 10 条，候选 10/20/50/100；所有受控状态从共享 `DEFAULT_PAGE_SIZE` 初始化，保留用户主动选择。完整列表通过分页访问所有记录，不用关闭分页铺满页面。网页具体规范见资产文档 `04-表格与查询.md`；客户端沿用同一共享分页入口，第二页排序必须保持完整集合索引。

## 日志查看与诊断

连续日志使用 `components/LogViewer`（@melloware/react-logviewer），不套用业务 Table 或每页十条分页。固定窗口内滚动、虚拟化绘制，按结构化 level 使用语义色并保留级别文字；信息蓝、警告橙、错误/致命红，调试采用次级文字。搜索沿用共享控件，级别与实际来源使用 MultiSelect 组合筛选，留空表示全部；保留真实五档级别，不将来源误当严重程度。通过事件持续接收日志，不提供暂停或普通刷新按钮；共享 LogViewer 按用户滚动意图与真实滚动容器位置控制跟随：上翻时保留阅读快照，后台持续接收；回到底部显示最新快照并恢复跟随，筛选或语言变化立即重新展示。初次读取失败仍提供重试。操作栏仅保留“导出”和“清空”；导出沿用脱敏诊断快照，不因简称改变文件内容。全部多行错误展开，不增加详情页。

应用日志保留原始文本、稳定事件标识、参数、会话和顺序号；双语目录只翻译应用文案，用户节点名、协议标记、错误码和第三方堆栈保留原文。新增应用日志需同步 `shared/log-catalog.json` 或 `log-extra-catalog.json` 的中文和英文，不能只追加某一种语言。后续可逐步将字符串调用迁移到显式事件接口；已有第三方输出没有可靠语义时不猜译。

磁盘 app.log 使用 JSONL，换行与堆栈按 JSON 转义，单条完整可解析；按顺序写入、轮转及清空。10 MiB 轮转，保留五个历史文件；内存最近 1000 条，界面最多 2000 条。普通待写上限 200，错误保留额外 200 容量，全部级别洪流也保持有界。丢写、丢 UI 帧、内存淘汰、写盘失败均计数，不以成功通知冒充全部落盘。

诊断文件按当前语言生成，含环境、配置、真实内核日志级别、会话/顺序信息、日志丢失计数、最近应用事件及 app.log/app.1.log/内核/提权启动日志。每文件尾部上限 64 KiB；等待应用写盘最多两秒，未完成明确记录。它是有限快照，无法保证任意问题仅凭一次报告就能定位。存储时间保留 ISO，阅读时间按设备时区转换。文件在用户选择位置保存，不自动上传；自由文本和配置都经过脱敏，仍需保留用户对访问域名的分享决定。

## 已安装应用

应用规则仅管理本机安装应用，与匹配规则合并到同一规则表，应用身份作为一条独立匹配规则。共用“新增”入口选择匹配规则或应用规则，应用规则打开可搜索应用选择器；不提供常用网站/服务页签，也不要求手填进程、域名规则集。用户选择去向与可选节点，保存不改变当前分流方式；共用系统网络服务等无法准确归属的应用保留明确能力限制，不用进程名猜测覆盖。

应用选择器、已配置应用列表、连接页完整明细和按应用出口图、连接页的应用来源，统一采用本机图标加名称。未知应用仍展示内核实际进程名称并使用统一占位图标，原始进程路径保留在连接页完整明细。图标只从本机读取，在运行时共享目录与有界缓存，不请求远端图标服务、不写入用户分流配置；读取失败不隐藏应用，也不改变分流能力。选择器打开时刷新安装目录。

不再自动注入内置服务规则。启动迁移只停用旧服务和手工预设对应的应用规则，保留其配置记录及真实安装应用的选择；普通网站规则继续由规则页管理。

网络流量统一通过 `src/shared/network-units.ts` 格式化：原始值保留字节，显示使用十进制 B/KB/MB/GB/TB/PB/EB（每级 1000），速率加 `/s`；随数值自动选单位，最多两位小数且不补零，舍入跨界同步升级单位。未知或非法采样显示 —，真实零值显示 0 B 或 0 B/s。连接流量列表共用，禁止只把 KiB 标签改为 KB 而保留 1024 换算。

## 未连接时的功能与连接观测

网站连通性、节点测试、订阅更新与管理、规则及应用分流编辑、日志、设置等不因代理内核停止而禁用；实际外网不通时显示真实失败。未连接的网站检测走普通网络，不自动启动代理；网站名称为语义蓝色链接，经宿主在系统默认浏览器打开对应官方页面，保留客户端页面与测试结果。

连接页出口图默认按应用展示，域名视角仅用于查看这些应用的目标；其计数、两种分组、搜索只展示有可靠进程路径和应用身份的用户应用；未识别进程、系统内置应用及后台服务不进入出口图，不根据访问域名猜测应用。应用身份依据已安装目录或标准应用安装目录中的实际 macOS 外层应用包，应用内 Helper 归并到外层应用。Windows/Linux 独立可执行文件须匹配已安装应用，不能以文件名认作应用。隐藏仅发生在出口图展示层，连接页保留原始完整快照，含未知连接、系统进程、目标端口、进程路径、出口链路、规则、协议和流量。代理路由默认启用 find_process，与是否配置应用分流规则无关。系统代理缺失路径时，在工作子进程按需读取本机套接字，仅用连接源 IP、源端口、协议与已知本机代理监听端口匹配唯一进程；不按目标域名或进程名称猜测。补充采集不改变内核出口、规则、流量或完整记录，不覆盖内核已有路径；观测失效、超时、歧义或 PID 冲突仍保留未知。没有连接订阅或窗口隐藏时停采集。权限或平台不能提供路径时保持未知，不能伪造识别结果。

连接页出口图和连接看板在未连接时读取操作系统当前可见的设备连接；内核运行时读取代理内核连接。快照标注 device/proxy 来源并丢弃不符合当前状态的过期帧。设备采集在工作子进程执行，按页面可见与订阅需求启动、停止，每轮完成后三秒采样，避免重叠或后台无消费者仍持续采集；不改变代理、路由或系统权限。

macOS 使用 lsof 的 NUL 字段与 ps 路径，Linux 使用 ss 与可读的 /proc 进程路径，Windows 使用 Get-NetTCPConnection 与进程目录。仅展示系统实际提供的已连接 TCP 与可识别对端的 UDP；Windows 当前只采集 TCP。权限不可见、未连接 UDP、容器或其他用户进程不能声称完整覆盖。没有可靠域名时按目标 IP 分组，没有逐连接字节或规则数据时显示 —；“系统网络”只是观测来源，不断言另一款 VPN 未接管该连接。读取失败就地展示错误，不伪装为已成功采集零条。平台适配须分别原生验证，解析器测试不等于跨平台实测。

## 内部分流数据（2026-10-08）

移除规则资源页面、目录、手动更新和 CRUD IPC；不保留旧资源引用或远程规则集兼容层。配置读写删除旧资源字段、依赖资源的完整规则、服务预设及其应用规则，清理本应用旧资源缓存。已安装应用分流依据真实进程路径，不使用网站清单猜测身份。

智能分流仍需要当前地区 GeoIP，局域网绕过仍需要私有域名数据。这些由后台按需准备和更新，失败保留有效缓存；没有有效地区数据时不得假装该地区策略已经可用。应用身份受操作系统可见性、接管方式和辅助进程影响，不承诺所有应用、所有平台 100% 命中。

## 运行中配置与软件更新（2026-10-08）

宿主偏好（外观、通知、启动、订阅调度、测速地址、更新调度等）不参与内核重启判断。节点和已有规则出口通过管理接口热切换；已外化规则的值通过文件热加载。异步配置应用串行执行，生命周期中的修改保留到完成后应用。内核结构变化仍合并后重启；重启后不得再次关闭新建立的全部连接，不承诺现有内核无法支持的零中断结构更新。

软件、内核、内部分流数据、订阅与测量由后台唯一更新入口按产品的六小时周期协调；依赖任务按顺序执行，独立网络请求限量并行，重叠范围合并。设置页“检查更新”仅检查软件版本和内核，不触发订阅同步或节点测速。订阅同步、连通性和测速手动入口只处理其对应范围，配置变更按实际依赖触发初始化。网络请求路径由后台统一管理，不保留逐订阅或旧全局路径开关。

检查只准备并校验更新。不影响现有代理的内容静默生效；运行中的内核替换、分流文件替换和订阅导致的内核配置变化暂存，右上角常驻提示可关闭，设置仍保留同一更新入口；新版本或新内容重新提示。一次“重启代理应用更新”合并所有准备好的代理侧内容。正常重新连接加载最新订阅配置后清除对应待生效状态。检查失败、部分订阅源失败、退避或缺少所需代理连接均保留失败状态，不冒充已是最新。关闭代理时可安全替换内核和分流数据；软件安装始终等待用户点击重启。

软件安装包后台下载到本应用数据目录的 updates，使用官方 SHA-256 校验；待安装状态原子保存，再启动重新校验摘要与文件，继续等待用户操作，不自动安装。离线保留有效待安装状态；损坏状态或安装包清理后重新检测。开发实例不检查或安装软件更新。内核自动选择当前兼容系列的稳定版本，跨配置兼容系列提示需升级软件，不盲目替换为不兼容的最新版。

macOS 更新器等待旧 PID 退出、校验应用标识并保留旧应用备份；新版完成主进程初始化后回传版本确认，收到确认才删除备份与安装包。启动未确认时恢复旧应用。Windows/Linux 沿用现有平台安装器，须使用正式产物逐平台验证；解析器、脚本语法或模拟测试不能替代安装实测。

## 节点筛选、实测状态与订阅信息

## 规则与分流方式

匹配规则和应用规则统一在一个表管理，从上到下匹配，越上方优先级越高，首次命中执行该条去向。支持两类规则混合拖动排序；例如域名代理规则置于应用直连规则之上，域名命中时走代理、其余该应用连接走直连。仅智能分流应用已启用规则；全部代理忽略这些规则，普通业务流量使用当前代理节点；直连忽略这些规则，普通业务流量直连。内核自身、DNS 启动及必要本地网络处理仍由基础路由管理。规则页明确显示当前模式与生效方式。新增和编辑规则不自动切换分流方式，既有应用记录及节点目标保留。移除独立应用分流页面和全局开关，旧配置关闭应用分流时，未被用户重新启用的其他应用规则保持停用。

新规则默认插入列表顶部，编辑保留原位置。旧应用规则按原先应用优先的实际顺序显示；首次保存或排序时转换到同一个 customRules 顺序列表，并移除对应旧 appRules 的重复路由。精确进程路径和应用目录（含 Helper）的匹配使用 process_path_regex，应用图标仅运行时读取，不持久化。

### 规则编辑条件输入

规则编辑只保留一个匹配条件列表，不同时展示主条件与额外条件。默认一条，单条不显示组合方式；两条及以上在条件列表顶部显示任一满足/全部满足，默认任一满足。先编辑条件，再设置去向，仅代理显示指定节点。规则不提供原始 JSON／完整协议字段编辑器；保存以实际条件为准，同步单条件字段，保留未展示的已有规则属性。空白或不符合类型的值在字段处校验，不提交。

地区筛选的候选项与选中值统一显示“地区图标＋地区名称”，复用节点身份的旗标资源与未知地区地球图标。筛选仍使用测量记录的地区代码，不新增地区查询。

规则匹配值先做必填校验，空字符串与纯空白统一提示填写；非空内容再按匹配类型验证格式，同一字段每次只显示一个错误。现有条件列表保留单层任一／全部语义，不引入用户筛选器的嵌套条件树与 JSON 视图。

匹配值统一使用 RuleValueField，由匹配类型管理格式说明、示例与校验。禁止使用 placeholder 承载提示或示例；说明和示例收进“匹配值”最小字段标签旁的问号 Tooltip，不在输入框下方常驻。校验错误仍常显。多个值仅按换行分隔，正则中的逗号与内部空格原样保留。切换匹配类型保留输入并按当前类型重新校验。

## 统一更新与测量持久化

`GlobalUpdateService` 是唯一自动更新时间入口：启动后 30 秒与每 6 小时执行完整维护；设置页手动检查仅准备软件和内核更新，不触发分流数据、订阅、测速、地区或网站检测。两个范围共用版本检查单飞与串行资源通道，后台维护不使手动按钮显示加载态。软件、内核与分流数据按依赖串行准备，订阅更新作为独立通道并行；两个通道完成后更新测量，订阅链接每次最多两组、每组两条路径并行，节点复用有并发限制的实际测速编排器。最近一分钟已完成的初始化或手动测量在同一轮合并，避免刚检测完再次检测。原各类调度器不启动独立定时器。网站结果也由同一周期刷新；网络地区识别和实时连接采集是网络生命周期机制，不是内容更新时钟。

节点测量、订阅链接连通性与网站结果统一保存至用户数据目录的 `measurements.sqlite`，SQLite 事务写入，文件权限 0600；不把测量或真实订阅链接放入仓库。节点旧 JSON 缓存在成功迁入数据库后删除。渲染页面仅读取保存快照并接收结果事件，页面访问不触发网络检测，也不轮询确认。

订阅预检、手动同步、自动同步和嵌套 provider 共用自动请求策略：先强制直连，网络或 HTTP 失败且代理可用时经固定代理入口重试一次。解析失败、安全校验拒绝和响应超限不触发重试；失败保留原节点。内核未运行时核验并固定物理路由，不能把实际经 TUN 的请求当作直连。请求标识由后台统一维护，表单及设置不提供旧代理开关、旧策略或请求标识覆盖；加载、保存和导入统一删除这些旧字段并持久化。链接连通性检测保持两条独立固定路径，不使用自动重试。

新节点、订阅链接及缺少结果的已有内容在启动或配置成功落盘后初始化一次；失败也是已知结果，保留原因和时间，随后按 6 小时或手动刷新。节点使用 ID、传输参数和测速目标指纹，订阅使用 ID、链接和有效 User-Agent 指纹；改名不丢结果，改变目标使旧结果失效。订阅和节点删除时清理孤儿记录，异步请求完成前重新核对最新配置，禁止写回已删除或已变化的目标。网站快照按实际路由上下文匹配，路由变化清理旧上下文；检测完成期间发生变化时禁止旧结果落库。

订阅链接仍独立测量强制直连和当前系统网络。节点入口延迟与经指定节点的代理延迟仍按固定流程执行，不跟随自定义分流规则；持久化与统一调度不改变测量路径。

配置保存后的自动化按不可变前后快照判定范围：节点组添加、编辑保存先同步该组订阅，再检测两条链接路径并重测组内全部可检测节点；明确保存即使值相同也触发这一流程。订阅同步返回 304 或内容等价仍刷新该组测量，但不替换节点、不重启内核。更新时间、额度等同步产物不再次触发订阅拉取，防止自动化循环。节点单项传输参数修改只重测该节点；成员增删、移组重测受影响组的存活成员；测速目标修改重测全部节点。主题、语言等无关偏好不产生网络检测。

恢复配置按导入类别扩大范围：订阅类别同步并检测导入的全部组，自建或组网类别检测该类别节点，完整节点配置检测全部。固定测速路径不因规则保存而改变；网站检测依实际出口和规则生效事件失效重测。六小时、手动和配置触发共用订阅同步请求，网络拉取可并行、配置写回串行；节点与链接任务合并重叠范围，测量过程中到来的新范围留待下一批，不丢变更。提交响应前重新加载配置并验证订阅链接；请求标识和自动更新路径由后台统一管理，不保留逐订阅覆盖。已删除或改变链接的来源不回写。自动同步失败保留原节点，仍对现存节点完成测量。


配置识别复用主进程的导入/订阅解析器，不提供“自动识别/手动协议”等模式下拉，不按地址、端口猜协议。订阅编辑只在请求来源改变后读取一次，自动解析全部支持协议，只显示协议数量摘要；加载、保存和导入删除旧 protocolPreference，不按旧协议偏好过滤。

节点分享内容仅本地解析，单节点编辑不接受多节点输入；支持单个分享链接、支持格式的节点配置以及本应用单节点 JSON。协议、传输、安全方式及其解析出的枚举参数显示只读结果，新增节点先解析配置；新请求使旧响应失效，识别失败保留输入并禁止保存，不允许提交过期结果。没有明确声明的可选参数沿用该协议已有默认语义，保留完整嵌套字段。地址、认证和其他实际配置字段仍允许就地编辑，未知协议或传输继续明确拒绝。输入格式说明只放最小标题旁问号，结果与校验常显。

连接应用身份与图标不能仅依赖固定安装目录：后台按观测到的完整进程路径读取外层应用包或原生文件图标，与已安装目录共享图标读取器。身份与图标按路径缓存、并发合并；初始图标读取不阻塞实时连接展示，不增设前端轮询。目录外的观测身份只用于显示，不自动登记为应用分流规则。路径不可读取时保留操作系统报告的进程名和 PID，不能丢弃现有身份后统一显示未识别；系统确实没有身份时继续明确未知。图表与表格共用简洁进程图标作为后备，不使用网格字符。

规则页概况使用共享 SummaryStrip 的 compact 状态样式：正文档字号，无外框，按网络地区（图标和名称）、分流方式、匹配顺序排列。规则生效范围、地区策略和拖动方法收进对应标题旁 HelpTip；匹配顺序保持统一规则列表的真实先后关系。

## 设置精简（2026-10-10）

提权助手放在设置首位，作用说明放标题旁 HelpTip；就绪时仅展示真实状态，未就绪时提供安装/修复，不暴露日常卸载动作。首次安装需操作系统管理员授权，不在打开界面时静默安装或反复请求；连接入口继续复用主进程统一 helper gate。缺少助手不阻挡节点、订阅、规则与日志管理；macOS 后台权限受系统控制，不声称重装能恢复被关闭的权限。服务清理由软件卸载生命周期负责，独立服务卸载能力仍保留给宿主生命周期。

常规保留开机启动、启动连接、托盘驻留、故障切换、外观和语言等用户意图。网络保留本地端口、局域网共享、直连/代理 DNS 与 IPv6，涉及其他客户端接入、共享边界或具体网络兼容，不能由程序猜测用户选择。移除 FakeIP、测速地址、局域网绕过、QUIC 和日志采集阈值的日常设置控件；后端同步删除对应旧配置：FakeIP 由统一运行策略开启、代理向 QUIC 自动保护、测速目标单源管理、日志使用 info（隐私模式 warn）。加载、保存及备份恢复共用集中清理入口，旧开关、旧目标、旧日志级别和无消费者的临时采集态不再写盘或影响生成。DNS、IPv6 与外部代理端口保留必要覆盖：DNS 可能承载内网解析，IPv6 依赖出口真实能力，端口可能被外部客户端固定引用；内部探针端口自动分配，不改变系统原有 DNS。不得把本机有 IPv6 地址冒充端到端 IPv6 可用。

更新区域仅展示当前软件和内核版本、软件与内核检查入口，以及确实存在的待应用重启动作；不常驻铺开检查时间和各模块结果，不保留手动替换内核/回退菜单。六小时后台更新调度不变，手动检查失败只反馈一次，诊断日志保留细节。备份导出与恢复归独立区块，恢复仍经过文件选择、类别选择和危险确认；仅打开设置不得改写配置。

助手状态查询、安装引导失败须传递真实错误，不能默认放行；已安装但未就绪的状态在各支持平台统一进入引导。移除旧“不再提示”配置以免隐藏前置条件。用户显式选择系统授权直接启动仍可执行：权限来自操作系统授权，不来自普通 Electron 进程。助手已就绪不等于内核或外部节点可用；必须确认进程及管理接口就绪后才发启动成功，缺少管理端口则停止本次内核并报错。

## 原生快捷菜单

Dock 与菜单栏/托盘共用一套业务菜单和真实连接状态：打开应用保留当前位置，连接/断开代理、选择实际存在的节点、智能分流/全部代理/直连、管理节点组、设置和全部测速。没有可用选择时连接不可点，没有节点或正在测速时不重复测速。管理节点组进入 `/nodes/groups`；窗口被自动释放后，导航等渲染器挂载完成再发送。菜单不暴露旧服务器页、手动轻量模式和重复检查更新；版本检查由设置页入口负责。关闭与空闲释放机制保留。Dock 退出采用 macOS 系统项，托盘保留应用退出项。

### 检测结果与缓存生命周期

共享 `background-refresh.ts` 是六小时有效期的唯一来源，主进程、渲染端与移动端共用时间戳判断：到期边界包含第六小时，损坏、未来或缺失时间戳不能阻止刷新。节点代理测量、订阅链接连通性、网站连通性、出口 IP、网络地区、分流数据文件和应用图标缓存使用此规则；失败结果使用相同有效期，避免短失败缓存导致请求风暴。历史结果可保留用于显示，但不能冒充当前可用性。

唯一维护周期负责后台更新，启动时补测缺失和过期结果；配置、节点、实际网络路径发生变化时立即失效并按依赖检测。移动端在服务启动时补测，页面读取不产生网络请求。订阅同步完成后重新检测所属节点与链接。删除独立内核定时器及其旧开关，配置加载、保存、恢复时统一移除旧字段。设置页手动版本检查仍仅检查软件和内核。

六小时策略不适用于请求超时、检测轮内有限退避、实时连接采样、提权助手健康检查、DNS 协议 TTL、下载完整性与权限验证。这些保持自身语义；缓存命中不替代连接成功或授权完成。内核更新继续保留摘要校验、兼容性预检和运行中不覆盖现役内核的保护。

## 2026/10/13 设计体系升级

本轮统一更新项目共享层、规范与门禁的设计基线，依据 React、Ant Design 公开 API 独立实现；采纳与保留差异以本节记录为准。

唯一品牌种子为 tokens.css 的 --ds-color-brand，默认 #1677ff；亮暗主操作蓝底白字，选择态品牌弱底，普通文字纯黑/白，未选中/禁用灰，状态色不随品牌变色。字号 12/14/16/20/24/28、正文14、普通控件32；布局和圆角保持统一 token。保留影字品牌资产、窗口固定栏、设备时区、常显内容和就地编辑，不采用后台实体多层路由。

节点、连接、日志的实际集合筛选经 QueryForm local/FilterSelect enum：同维度 OR、跨维度 AND，空数组不限；不保留全部哨兵或重置筛选按钮。来源、应用、出口、协议、地区与多状态属于可组合维度；分流方式和排序是业务控制、不是实体筛选。实时或已经完整加载的数据即时过滤，不额外触发服务端请求；以后服务端分页使用提交快照。静态协议候选来自共享完整支持目录，不因当前无记录消失。动态候选来自完整集合并保留已选对象。字段与真实列/集合绑定及全表清单登记 web/scripts/design-system.project.json。

表格全部左对齐、数字等宽，操作尾列固定右侧。连接按可见目标自然顺序，节点组按可见名称自然顺序，在完整集合排序后分页；规则和节点配置保持真实业务顺序。普通长值独立 AtomicValue 横滚，详情全文折行；Firefox 不依赖 td 滚动，滚动条统一 thin/2px。共享表格量真实内容收束列宽、保留短值和长值头尾，禁止省略或裁切。

DrawerForm 在 Form 正文挂载时恢复初值、清理销毁，覆盖 StrictMode 重演；普通重渲染不覆盖草稿。未修改关闭，修改后取消/保存，失败保留草稿。门禁包含新查询 AST 正反例、完整表格清单、自然排序单测与双浏览器真实滚动/表单回归；不能以迁移包摘要替代项目验收。

开发阶段 `check:affected` / `check:staged` 读取 Git 实际输入：业务 UI 选择其静态、字段、翻译、类型、lint 与单元依赖；共享层、工具编排、依赖或未知基线保留全部快速门禁。纯文档变化不触发前端编译。交付仍运行全部静态、构建以及 Chromium/Firefox，部分验证不替代交付。

共享详情网格通过自然值上下文取消后代原子横滚，普通表格/候选长值才登记横滚槽；不能一边声明全文折行一边保留禁止折行的运行时元数据。条件表达式翻译键的所有确定分支都要审计，缺失分支必须使静态门禁失败。
