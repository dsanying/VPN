# 暗影VPN 品牌图标

以「影」字为唯一标志，黑色圆角底、银白字形。右侧三撇分开，采用同方向的微弧笔势，底撇收短，保持与左侧「景」的视觉平衡。中英文界面共用这个标志，不再以产品名首字或首字母替代。

矢量母版为 `build/brand/mark.svg`，没有字体依赖。`npm run brand:generate` 从母版生成全部资源：应用 PNG、Mac ICNS、Windows ICO、Linux 尺寸集、网页与界面 SVG、Android 自适应前景与旧系统启动图、通知栏单色图，以及菜单栏和托盘图。生成文件不分别手工编辑；`npm run brand:check` 校验所有衍生文件与母版一致，构建和准备安装包时自动执行。

Mac 菜单栏使用透明底模板图及双倍分辨率资源，由系统适配明暗背景；连接状态附加一个小圆点，具体状态仍由提示文字及菜单表达。Windows/Linux 托盘使用黑底银白图，连接时附绿色圆点。Android 自适应图标的前景保留系统裁切安全空间，通知图标只使用字形透明度。资源缺失时的内置兜底也使用同一字形，不回退到字母 V 或旧标志。

正常安装仍原位替换 `/Applications/暗影VPN.app`，不创建第二份安装或修改用户配置。原生图标最终效果以对应系统为准；本机未运行的 Windows/Linux 不能仅凭资源生成就宣称已经验收。
