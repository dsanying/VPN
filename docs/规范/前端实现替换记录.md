# 客户端实现替换记录

原组件库许可与历史项目源码许可分别核验；本记录不把 Ant Design 的开源许可授予历史专有源码。来源审计未结束前禁止公开分发未解决的源码。

客户端共享层通过 React、Ant Design、ECharts 公开 API 独立实现，保留既有产品外观与交互契约。2026-10-11 移除实际入口不可达的 116 个历史注册源码，包括账户后台组件、金融图表、未使用的请求包装与表单组件。生产入口为 main.tsx 与 update-popup/main.tsx，保留真实客户端业务、数据库及原生桥。

随已移除组件运行的两套历史演示夹具和四个专用测试文件同步退役；这些夹具不再代表实际客户端。适用要求由独立 client-contract.spec.ts 与业务测试验证：分页默认十条、20/50/100 候选、完整集合访问及第二页排序，保存失败保留输入、取消还原、成功关闭，亮暗主题、多选清空、字段问号和窄窗。节点列表独立滚动由 nodes-filters 验证；出口图完整集合、标签、图标、筛选和语义颜色由 connections-live-traffic、connection-identities、connection-semantics 验证。规则摘要、设置保留项及提示宽度继续有专项测试，未删掉对应业务门禁。

CSS 主题输出由 generate-client-tokens.mjs 按产品角色生成，单一颜色、几何和语义色入口；全局文档样式、i18next 接入、主题映射及图表包装独立实现。字典按当前源码引用保留 361 个键，先展开嵌套再清除未使用词条。历史静态检查器的 29 个入口、配置与测试退役，由独立 client-checks 编排 AST 正反例、时间、主题、双语参数、单元测试、实际依赖补丁、类型、零警告 ESLint、构建和全部业务浏览器测试。来源登记及其他历史文件仍须审核，不应据本记录声称全部分发边界已解决。

2026-10-11 后续校准：删除四个未登记实际边界的历史构建插件文件；运行入口、依赖安装审核及运行时补丁审核改为独立实现。旧 forced-wrap 的历史选择器未覆盖当前表格与操作组，已用 client-geometry 的标准 DOM/CSS 检测替换，并增加六组正反夹具。新的单元格、查询控件与并排指标检查直接对应当前客户端类名；历史固定图表与后台面包屑测试不再冒充当前产品要求。当前源码许可审核仍未结束，保留历史来源声明，不据文件摘要改变宣布授权完成。
