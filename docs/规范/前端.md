# 前端规范入口

客户端适配优先遵循 [客户端规范](客户端.md)：内容始终展开、主内容在窗口内滚动、全局状态常驻且不重复。以下网页基线规则仅在没有客户端冲突时适用。

客户端实现要求记录在 [前端规范](前端/README.md)；检查入口以 [manifest.json](manifest.json) 为准。

暗影VPN 的适用范围是 Electron 客户端。首页、节点、规则、应用分流、规则资源、连接、日志和设置为平级页面；不采用管理端对象详情页流程。桌面标题栏、状态栏、IPC 和提权助手以本项目运行机制为准。具体适配及证据见 [前端改造](../前端改造.md)。其余主题、共享组件、双语文案与门禁规则按正文执行。
