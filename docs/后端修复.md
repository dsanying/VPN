# 后端修复说明

当前主分支在 FlowZ 4.3.3 基线直接修改，沿用其前端、IPC、配置模型和 sing-box 1.14.0-rc.1。未将早期独立原型作为产品主实现。

## 订阅请求与识别

原 `defaultSubscriptionUserAgent()` 返回 `FlowZ/<app.getVersion()>`，是客户端标识，不是节点协议。当前默认发送 `clash.meta` 协商供应商常见格式，后端依据响应内容自动解析 Clash、sing-box、Xray 或分享链接，不依据 UA 推断节点协议。标准 UA 也不能强制供应商返回某种内容。

订阅的 `protocolPreference` 缺省或 `auto` 表示导入所有支持协议；显式值只保留该协议。预检、手动更新和定时更新使用同一过滤函数；URL、UA 或协议选择改变时清除 HTTP 条件请求 validators，避免 304 阻止重新筛选。编辑时先预检，刷新失败恢复原选择；无匹配抛错，避免清空原节点。原有显式自定义 UA 配置保留兼容，但普通表单不再展示 UA 输入框；编辑时清除旧 FlowZ 标识。

Clash HTTP `headers.Host` 可为数组，原实现仅收字符串，导致 Host 丢失；同时补齐 method 与额外 headers。WS 保留额外 headers。sing-box HTTP 与 WS JSON 也保留这些字段。Host、SNI 和节点地址仍分别映射，不互相覆盖。

不支持的传输（例如当前 sing-box 模型未支持的 XHTTP）继续拒绝并记录原因，不生成“能导入但无法使用”的裸 TCP 节点。界面协议选项不代表每种协议在每个平台均已真机验收。

## 测速

保留真实代理 CONNECT 隧道和同连接两次 GET 的 warm TTFB 算法；限制并发为 4，默认 HTTPS gstatic 失败后用 HTTPS Cloudflare 独立复核。自定义目标保留用户选择。TLS 证书验证开启，信任系统和默认 CA，不绕过证书错误。

失败诊断区分 `timeout`、`connect-*`、`http-*`、`tls-error:<code>` 等；列表统一显示“不可达”，避免把握手重置误写成“超时”。备用失败原因保留于诊断中。使用完整节点 ID 构造测速标签，关闭 CONNECT 拒绝后的 socket，消费作业清理 Promise，临时配置权限为 0600。账户流量及到期通知伪节点排除测速统计。

默认目标对 HTTPS 的检查比明文 HTTP 更严格；HTTPS 失败不能推导所有目标均失败。测速延迟不等于带宽，成功仅证明该时刻对测试目标的代理请求成功。
