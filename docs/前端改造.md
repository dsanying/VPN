# 暗影VPN 前端改造

当前客户端共享 React + Ant Design 界面。macOS/Windows 使用 Electron，Android 使用 Capacitor；平台能力、构建与发布边界见 [平台与发布](规范/平台与发布.md)。原 `src/renderer/` 与 Flutter 试验入口已移除，实际界面入口为 `web/src/main.tsx`。不运行第二套业务界面。

## 界面与业务

节点、连接、规则、日志和设置为统一导航入口。节点页保留选择、连接、分流、筛选与完整节点列表；管理按钮进入节点组表格，订阅新增、编辑、删除、同步及两种订阅链接连通性集中在组管理。筛选读取已经维护的数据，不触发网络检测。订阅与单节点配置从内容识别，保留完整协议参数；识别失败保留输入并禁止猜测保存。

连接页展示真实连接及出口图；应用身份与图标统一解析，缺失进程信息保留实际可知的名称或 PID，不把选中节点当作每条连接出口。图表在语义结构变化时更新，流量变化不重建图形。日志持续接收事件，级别多选，保留导出与清空。规则摘要按地区、分流方式、匹配顺序展示；排序优先级与拖动操作对应。

设置保留需要用户选择的行为及网络参数，解释位于对应最小标题旁的问号。桌面提权助手与 Android 系统 VPN 授权按平台能力展示；未确认系统接管不报告连接成功。设置的检查更新仅检查软件与内核，不触发订阅同步和节点测速。导出恢复使用统一校验、迁移与数据库持久化。

内容分区始终展开，导航、状态栏固定在窗口内，正文与节点列表按实际高度滚动。亮暗主题、简体中文/英文、窄窗、表单失败保留和通知遵循 [客户端规范](规范/客户端.md)。没有无用途的示例文案；字段错误仍就地展示。Android 使用相同前端布局与共享业务，平台无法执行的功能必须由能力契约约束，不能显示虚假的可用状态。

## 后台与持久化

桌面和 Android 共享解析、规则、配置、更新与维护业务。Android 后台运行于 Application 所有的 JavaScriptEngine，界面仅调用类型化业务桥；原生层负责 SQLite、HTTPS、VPN、权限、文件和内核能力。视图退订与后台任务释放分别管理，没有为了后台运行保留隐藏 Activity 或第二份业务引擎。

维护采用一个六小时调度入口并按变化范围执行依赖步骤；手动触发、配置引入/变更与初始化进入同一机制。订阅同步后重新检测对应节点组，结果和时间写入数据库；删除或配置身份改变时清理失效关联，失败保留原节点。不以每次进入页面或两秒轮询作为完成确认。实时连接等确有实时需求的内容用事件订阅并随可见性释放。

## 来源和验证

公开依赖的许可、内核对应源码和补丁说明见 [NOTICE](../NOTICE.md)；历史本地专有模板的替换与复核范围见 [实现替换记录](规范/前端实现替换记录.md)。保留产品设计不代表沿用专有实现或取得原版权授权。

静态检查包括类型、零警告 lint、AST 正反例、文案、主题、时间和依赖审核；浏览器专项与完整回归验证真实业务页面。原生安装包必须另验启动、布局、操作、网络、开机行为和更新；浏览器或交叉构建通过不能替代平台实际验证。当前覆盖范围及未完成项以平台报告为准，不宣称所有供应商节点或未验平台均已可用。测试仅使用虚构节点与 example.com，真实订阅和凭据保留在仓库外。
