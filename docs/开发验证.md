# 开发验证与本机安装

本机只保留 `/Applications/暗影VPN.app` 作为正常安装。原位替换应用保留仓库外的用户数据和常驻助手；不要把验收目录复制到应用程序目录，也不要在隔离配置中重装助手。验收完成自动注销该副本的 LaunchServices 登记。

`npm run package:mac:local` 清理旧候选、执行按输入缓存的开发门禁，只生成当前 Mac 架构的目录包，固定输出 `dist-native-candidate`，不生成双架构压缩安装包。验证和本机打包各自有互斥锁，拒绝同时运行第二个入口；中断后的遗留锁须先核实原进程已结束。结束验收后执行 `npm run clean:native`：拒绝清理仍在运行的候选，仅删除本仓库明确声明的生成目录，不访问正式安装、用户数据或其他项目。发布产物需要保留时先移到专门的交付目录；清理入口也会删除本仓库 `dist-package`。

日常使用 `npm run validate:dev`。每项检查分别按实际源码、锁文件、工具链、平台与架构计算摘要；真内核检查还包含本机实际二进制。只有输入一致、上次真实执行成功且原日志未被篡改时才复用。源码新增、删除、依赖或工具链变化会使受影响检查失效；失败立即清掉该检查的缓存。结果保存在 `artifacts/development-validation`。

`npm run validate:dev -- --plan` 只展示计划；`--only lint,renderer-types` 用于当前专项反馈，不代表完整验证。没有有效基线会执行全部五项：默认测试、lint、渲染类型、真内核、构建。完整交付前运行 `npm run validate:full`；正式发布 CI 与原生发布门禁继续强制完整验证，不接受开发缓存作为当前提交的原生发布证据。

改 Android 原生代码时，桌面源码摘要没有变化就复用桌面验证，只构建并验证 Android；改前端或共享业务时重跑对应检查与受影响宿主。单个平台失败修复后先验证该平台，不重复构建无关平台。原生助手、Android 工具链和各平台安装升级仍需独立专项，以上开发入口不宣称覆盖这些能力。
